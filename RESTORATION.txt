Transcription Studio source restoration — 2026-11-20

CURRENT STATUS: this tree now includes the 0.1.16 Alpha Eval and project

This is a reconstructed source tree, not a byte-for-byte recovery of the
deleted October working directory. The installed application was not changed.

Sources:
- Base: D:\github\babel\transcription-studio (preserved unchanged).
- tmp\eval2: evaluation.rs, actions.rs, updater.rs.
- tmp\eval-audio-fix: mod.rs, evaluation_audio.rs.
- tmp\chunk-audio-fix: babel_audio.rs, chunk_audio.rs, subaccounts.rs.

Reconstructed integration:
- Eval / Eval 2 dashboard routing, state, messages, rendering and timer.
- Audio playback completion and Symphonia decoders / streaming WAV support.
- Relay evaluation endpoint with serialized session ownership, project
  assignment and task checks; ownership persists across relay restarts.
- Local relay random owner token and owner request authentication.
- Console Babel-service helper and tRPC transport; evaluation mutations
  are sent once, without automatic retries.
- Chunk audio URL requests for transcription tasks.

Build:
  cargo build --offline -p studio-app --bin transcription-studio --bin studio-babel-service -p studio-relay --bin studio-relay
  powershell -File tools\package-restored.ps1

Tests:

  cargo test -p studio-app --bin transcription-studio --offline -- --test-threads=1
